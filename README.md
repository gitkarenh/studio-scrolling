# studio-scrolling
Una plataforma estilo Instagram que transforma tus materias en un **feed de estudio interactivo y adictivo** (microlearning). Incluye **mentores de IA** que te muestran salidas profesionales y contenidos **adaptados a tu estilo de aprendizaje** (visual, práctico o auditivo) para estudiar sin aburrirte y prepararte para el empleo.
